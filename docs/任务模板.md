# 执行者任务模板

`summary` 继续写给人看的一两行结果；`description` 写给执行者，按 `goal:`、`ctx(file:line):`、`do:`、`accept(cmd -> expect):`、`limits:` 五段组织。上下文只列本卡必要入口；未核实的位置写“待定位”，不要编造行号。`acceptance` 与 accept 段保持同一命令和预期，说明退出码、断言或产物。

运行 `python cli/board.py create --template` 可离线查看 JSON；也可复制 `examples/任务模板.json`，填写后用 `python cli/board.py create --file task.json` 建卡。模板只使用现有字段，旧 JSON payload 仍原样提交。示例默认未放行；填写 `verifyCmd` 时仍须使用操作者已登记的验证键。模板不能替代预算、权限、人工确认或放行授权。

拆解器及派生卡沿用同样的说明结构。父 run 绑定、重复任务判定、角色权限和放行规则仍按现有流程处理。
